# Review Tags

Редирект по NFC/QR-меткам со счётчиком переходов, кабинет клиента и админка. Один проект Next.js, одна БД Neon.

- `/r/[code]` — редирект на форму отзыва и запись клика
- `/login`, `/cabinet` — вход клиента и его статистика
- `/admin` — только для админа: создание клиентов, меток, смена ссылки, сброс пароля

## Что нужно сделать вам

1. **Проверить сборку локально.** Проект написан, но не собирался: в среде, где я его создавал, был закрыт доступ к npm.
   ```bash
   npm install
   npm run build
   ```
   Если `build` ругнётся (опечатка, тип, версия пакета), пришлите вывод, поправлю.
2. **Создать базу в Neon** (neon.tech, бесплатный тариф). Скопируйте Connection string.
3. **Выполнить `db/schema.sql`** в SQL Editor в Neon.
4. **Создать `.env.local`** по образцу `.env.example`:
   - `DATABASE_URL` — строка из Neon
   - `SESSION_SECRET` — результат `openssl rand -base64 32`
5. **Создать себе админа:**
   ```bash
   npm run create-admin -- you@mail.com 'надёжный-пароль'
   ```
6. **Запустить локально** (`npm run dev`), зайти на `/login`, создать тестового клиента в `/admin`.
7. **Залить в GitHub и подключить к Vercel.** В Settings → Environment Variables добавьте те же `DATABASE_URL` и `SESSION_SECRET` (можно подключить Neon через Vercel Storage, тогда `DATABASE_URL` добавится сам).
8. **Регион функций** поставьте ближе к региону БД Neon (Settings → Functions), иначе редирект будет медленнее.
9. **Проверить ссылку на форму отзыва** на iPhone и Android до записи меток. Для 2GIS формат ссылок меняется, проверяйте вручную.
10. **Записать метку:** в приложении для NFC (например, NFC Tools) запишите URL `https://ваш-проект.vercel.app/r/<код>`. **Не включайте «только чтение»**, чтобы позже перезаписать на свой домен.
11. **Подключить свой домен** до печати QR-кодов: QR на носителе перезаписать нельзя.

## Заметки

- Vercel Hobby формально только для некоммерческого использования. Для пилота терпимо, с первыми деньгами переходите на Pro.
- Если в `lib/url.ts` нет домена вашей ссылки, добавьте его в список `ALLOWED`.
- Пароль клиента показывается один раз при создании. Потерял — «Сбросить пароль» в админке.
- Нет защиты от перебора пароля. Перед реальными клиентами добавьте rate limit на `/login` (например, Upstash Ratelimit).
- Боты и превью мессенджеров отфильтровываются по User-Agent и не попадают в статистику, но сырые записи в `clicks` остаются.
- Часовой пояс статистики: `Asia/Almaty` (в `components/Stats.tsx`).
